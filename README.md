# 🌤️ Weather App | تطبيق الطقس الذكي

تطبيق طقس حديث ومبتكر يوفر تجربة ممتعة ودقيقة لمعرفة حالة الطقس لحظة بلحظة. تم تصميمه بعناية فائقة ليعطي أداءً سريعاً وواجهة مستخدم عصرية تناسب جميع الأجهزة.

---

## 🌟 المميزات الرئيسية

- 📍 **تحديد الموقع التلقائي:** يقوم التطبيق بتحديد موقعك الجغرافي وحالة الطقس لمدينتك تلقائياً وبدقة عالية دون الحاجة للبحث اليدوي.
- 🎯 **دقة متناهية:** يعرض درجات الحرارة والبيانات الجوية لمدينتك بدقة متناهية اعتماداً على مصادر جوية موثوقة.
- ⏰ **توقعات بالساعات:** عرض تفصيلي لتغيرات حالة الطقس ودرجة الحرارة خلال الساعات القادمة من اليوم.
- 📅 **توقعات الأيام القادمة:** نظرة شاملة وتوقعات جوية دقيقة للأيام القادمة لتساعدك في التخطيط ليومك وأسبوعك.
- 🎨 **تصميم رائد ومميز:** واجهة مستخدم بيئية وعصرية تم الاعتناء بكل تفاصيلها البصرية لتقديم تجربة فريدة.
- 📱 **استجابة كاملة (Responsive):** متوافق تماماً مع جميع أنواع الشاشات والأجهزة (أجهزة الكمبيوتر، التابلت، الهواتف الذكية).

---

## 🛠️ التقنيات المستخدمة

تم بناء المشروع باستخدام التقنيات الأساسية للويب بالإضافة إلى مكتبات خفيفة ومميزة:

- **HTML5:** لبناء هيكل الصفحات والدلالات البرمجية.
- **CSS3:** للتنسيق المتقدم، الأنيميشن، وتجربة المستخدم البصرية.
- **JavaScript:** لمنطق التطبيق، الربط مع الواجهات البرمجية (APIs)، وتحديث البيانات ديناميكياً.
- **مكتبات خارجية (External Libraries):**
  - مكتبات أيقونات حركية ومؤثرات بصرية لإضافة لمسة جمالية للتطبيق.
