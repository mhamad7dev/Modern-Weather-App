# 🌤️ M.D Weather App

> **نظام طقس ويب فاخر، ذكي، وسريع — مبني بأحدث تقنيات الويب.**

---

### ✨ المميزات الرئيسية
* ⚡ **تحديد موقع فوري:** كشف موقعك الجغرافي بثوانٍ معدودة وبدقة عالية.
* 🌡️ **درجات حرارة حقيقية:** بحث عن أي مدينة في العالم مع عرض البيانات الأصلية والموثوقة 100%.
* 💎 **تصميم عصري فاخر:** واجهة ليلية (Dark Mode) مريحة للعين وتفاصيل بصرية مبهرة.
* 📱 **متجاوب تماماً:** يعرض بجمالية وانسيابية على كافة الأجهزة (جوال / آيباد / كمبيوتر).
